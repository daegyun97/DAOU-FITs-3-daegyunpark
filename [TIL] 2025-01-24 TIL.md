### 오늘 내가 새롭게 배운 것은 무엇인지?
 - WITH 명령어
      ```
         WITH DEPARTMENTSALARY AS(
            SELECT DEPARTMENT_ID, ROUND(AVG(SALARY),2) AS AVG_SALARY
            FROM EMPLOYEES
            GROUP BY DEPARTMENT_ID
            ORDER BY DEPARTMENT_ID NULLS LAST)
        SELECT *
        FROM DEPARTMENTSALARY
        WHERE AVG_SALARY>5000;
        
        WITH NUMBERS (NUM) AS (
            SELECT 1 AS NUM
            FROM DUAL 
            UNION ALL
            SELECT NUM + 1 AS NUM
            FROM NUMBERS
            WHERE NUM<10
            )
        SELECT B.NUM
        FROM NUMBERS B;
      ```

 - 사용자 정의 함수
 - REDO, UNDO
   - REDO : 변경 복구를 위한 로그(비정상종료)
   - UNDO : 이전 상태 저장(커밋 복구)
